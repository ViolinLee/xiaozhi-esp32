# Spippy（斯皮皮）四足机器人 BSP

## 简介

Spippy 是一套面向 ESP32-S3 四足机器人的小智 BSP。固件在同一颗主控上完成语音交互、八路舵机控制、OLED 表情显示、超声波感知、电池保护和局域网页面校准，无需额外的运动控制主板。

主要能力包括：

- 小智语音对话及 MCP 机器人控制；
- 前进、后退、转向和多种表演动作；
- 三档运动速度及步数、定时、持续三种移动模式；
- 128 × 64 OLED 表情和状态显示；
- 超声波距离感知、接近互动和前进避障；
- 低电量禁动、蜂鸣器提醒和安全姿态；
- 八路舵机网页预检、零位校准和 NVS 持久化；
- 空闲自主互动，可在网页中启用或关闭。

## 硬件概览

| 项目 | 配置 |
| --- | --- |
| 主控 | ESP32-S3 |
| Flash | 16 MB |
| 音频输入 | I2S 数字麦克风，16 kHz |
| 音频输出 | I2S 功放/扬声器，24 kHz |
| 显示 | 128 × 64 SSD1306 OLED，I2C |
| 运动控制 | 四腿 × 两关节，共 8 路有效舵机 |
| 距离传感器 | 单路超声波测距 |
| 电池检测 | ADC 分压采样，面向 2S 电池电压范围 |
| 本地提醒 | PWM 蜂鸣器 |
| 网络 | 2.4 GHz Wi-Fi，内置配网和校准网页 |

## 引脚定义

### 音频、显示与传感器

| 功能 | GPIO | 说明 |
| --- | ---: | --- |
| OLED SCL | 1 | 默认 400 kHz |
| OLED SDA | 2 | 默认地址 `0x3C` |
| 麦克风 WS | 4 | I2S 输入 |
| 麦克风 SCK | 5 | I2S 输入 |
| 麦克风 DIN | 6 | I2S 输入 |
| 扬声器 DOUT | 7 | I2S 输出 |
| 电池 ADC | 8 | 电池分压采样输入 |
| 扬声器 BCLK | 15 | I2S 输出 |
| 扬声器 LRCK | 16 | I2S 输出 |
| 超声波 ECHO | 47 | 回波输入 |
| 超声波 TRIG | 48 | 触发输出 |
| 蜂鸣器 | 45 | PWM 输出 |
| BOOT 按钮 | 0 | 对话、配网及网页地址显示 |

### 舵机

| 位置 | 关节 1 | 关节 2 |
| --- | ---: | ---: |
| 左前腿 | GPIO9 | GPIO10 |
| 右前腿 | GPIO40 | GPIO39 |
| 左后腿 | GPIO12 | GPIO11 |
| 右后腿 | GPIO21 | GPIO38 |

固件为扩展机构预留了 GPIO13、GPIO14、GPIO41、GPIO42 四个 PWM 通道，但当前四足步态只使用上述 8 路有效舵机。

### 其他接口

| 接口 | GPIO |
| --- | --- |
| UART1 TX / RX | 17 / 18 |
| USB D- / D+ | 19 / 20 |
| UART0 TX / RX | 43 / 44 |

> 舵机应使用满足峰值电流要求的独立电源，并与 ESP32-S3 共地。不要直接用 ESP32-S3 的 3.3 V 引脚为舵机供电。

## 编译与烧录

本 BSP 使用 ESP-IDF 5.5.x。请先完成仓库要求的 ESP-IDF 环境安装和导出。

### 推荐：自动构建发布固件

在项目根目录执行：

```bash
python3 scripts/release.py spippy
```

脚本会自动完成以下工作：

1. 选择 `esp32s3` 目标；
2. 启用 `CONFIG_BOARD_TYPE_SPIPPY`、唤醒词、音频处理器和 MCP；
3. 使用 16 MB 分区表；
4. 下载组件依赖并编译固件；
5. 生成 `build/merged-binary.bin`；
6. 打包为 `releases/v<版本号>_spippy.zip`。

首次烧录建议使用 ZIP 中的 `merged-binary.bin`，从 `0x0` 写入：

```bash
esptool.py --chip esp32s3 write_flash 0x0 merged-binary.bin
```

### 应用镜像与合并镜像的区别

`build/xiaozhi.bin` 只是应用镜像，不是完整固件，不能写到 `0x0`。本 BSP 的默认烧录布局为：

| 地址 | 文件 |
| ---: | --- |
| `0x0` | `bootloader/bootloader.bin` |
| `0x8000` | `partition_table/partition-table.bin` |
| `0xD000` | `ota_data_initial.bin` |
| `0x20000` | `xiaozhi.bin` |
| `0x800000` | `generated_assets.bin` |

已经具有正确 bootloader、分区表和资源分区的设备，才可以把 `xiaozhi.bin` 单独写到 `0x20000`。全新设备或分区发生变化时，应烧录 `merged-binary.bin` 或使用 `idf.py flash` 写入全部分区。

### 手动编译

```bash
idf.py set-target esp32s3
idf.py menuconfig
```

在 `Xiaozhi Assistant -> Board Type` 中选择 `Spippy四足机器人`，并根据 [`config.json`](config.json) 启用相同的音频、唤醒词、MCP 和分区配置，然后执行：

```bash
idf.py build flash monitor
```

## 首次启动与按键

1. 上电后等待设备进入配网流程，按小智项目的通用方式完成 Wi-Fi 配置。
2. 启动阶段尚未联网时，短按 BOOT 会清除已保存的 Wi-Fi 并重新进入配网。
3. 正常运行时，短按 BOOT 用于开始或结束一轮对话。
4. 已连接局域网时，长按 BOOT 会在 OLED 上显示 Spippy 网页地址。

## 语音控制

Spippy 通过 MCP 工具把自然语言转换为机器人动作。用户无需记忆工具名，可直接说：

- “向前走 5 步”“后退 3 步”；
- “左转两步”“向右转”；
- “向前走 10 秒”；
- “一直向前走，直到我说停”；
- “停下”；
- “慢一点”“切换到快速”；
- “挥挥手”“鞠个躬”“做两个俯卧撑”；
- “跳个舞”“表演一下你的功夫”；
- “做个开心的表情”；
- “现在电量多少”“前方距离多远”；
- “告诉我校准网页地址”。

### 移动模式

| 模式 | 用途 | 限制 |
| --- | --- | --- |
| `steps` | 按完整步态周期移动 | 1–50 步，默认 3 步 |
| `duration` | 至少移动指定时长，在完整周期边界停止 | 500–30000 ms |
| `continuous` | 持续移动，直到收到停止指令 | 默认 30 秒安全超时 |

前进、后退和转向使用低、中、高三档速度。连续运动不会无限执行，到达安全超时后会自动停止。

### 表演动作

| 类别 | 支持动作 |
| --- | --- |
| 互动 | 挥手、点头、鞠躬、恭喜、撒娇、卖萌晃动 |
| 体能 | 俯卧撑、抖动、前后摇摆、蹦跳、摆姿势 |
| 情绪 | 困惑、害怕、生气、困困、吓一跳 |
| 娱乐 | 两组舞蹈、唱歌、武术表演 |
| 姿态 | 坐下、趴下、呼吸、右后腿撒尿 |

还可以使用“卖萌”“跳舞”“功夫”“全部”等展示模式，连续执行预设动作组合。

## 舵机预检与校准

设备连接 Wi-Fi 后会启动局域网页面。优先访问：

```text
http://spippy.local/spippy
```

如果当前网络或终端不支持 mDNS，可以长按 BOOT 查看 IP 地址，或直接询问机器人“校准网页地址”，然后访问：

```text
http://<设备IP>/spippy
```

建议按照以下顺序操作：

1. 将机器人放在稳定、宽敞的位置，使腿部没有外力阻挡。
2. 使用“舵机预检”确认各通道能够正常响应；预检结束后机器人会恢复正常待机。
3. 点击“开始校准”，机器人进入 90° 安全基准模式。
4. 按左前、右前、左后、右后的顺序，逐个调整两个关节的零位偏移。
5. 确认姿态正确后点击“保存并完成”，校准值会写入 NVS。

校准和预检互斥，运行其中一项时会锁定普通运动。取消校准会撤销本次未保存的修改。低电保护生效时不能启动舵机预检或运动。

网页右上角还可以开关“自主互动”；设置会保存到 NVS，重启后继续生效。

## 安全策略

### 前进避障

- 默认在前方距离小于等于 280 mm 时禁止前进；
- 障碍解除后，需要距离达到 350 mm 并连续确认，才会恢复前进；
- 传感器刚启动、数据过期或状态不确定时采用保守策略，禁止前进；
- 前进过程中检测到障碍或传感器数据失效，会立即停止；
- 后退和原地转向不受前向距离门限限制。

### 低电保护

- 默认连续检测到电池电压不高于 7.4 V 后进入低电锁定；
- 低电锁定会停止动作、清空队列、切换安全姿态并启动蜂鸣器提醒；
- 电压恢复到 7.6 V 以上并连续确认后解除锁定；
- 低电期间允许查询状态和电量，但拒绝新的运动与表演动作。

具体门限、确认次数、采样周期和蜂鸣器间隔均可在 `menuconfig` 的 `SPIPPY_CONFIG` 中调整。

### 自主互动

自主互动默认开启。机器人空闲约 60 秒后进入候选状态，之后按随机间隔执行轻量动作；有人靠近时也可以触发接近互动。以下情况会抑制自主动作：

- 正在对话或执行用户动作；
- 低电保护生效；
- 正在校准或舵机预检；
- 前方距离过近或传感器状态不安全。

## 小智角色设定建议

为了让模型更稳定地调用机器人工具，可以在小智后台角色设定中说明：

> 你是 Spippy（斯皮皮）四足机器人的大脑。你可以聊天，也可以控制自己的移动、动作、速度和表情。用户给出步数时使用步数模式，给出时间时使用定时模式，说“一直走”时使用持续模式。用户要求停止时立即停止。运动或表演被低电保护拒绝时，要明确提醒用户充电；前进被避障拒绝时，要说明前方有障碍或距离传感器状态不安全。用户询问电量、距离或校准网址时，应调用对应工具获取实时信息，不要猜测。

## 常见问题

### 机器人无法移动

依次检查：

1. 电池是否进入低电锁定；
2. 是否仍处于校准或舵机预检模式；
3. 前进指令是否被超声波保护拦截；
4. 舵机电源是否充足并与主控共地；
5. 网页状态或 `self.robot.status` 返回的错误码。

### 校准网页打不开

- 确认设备和手机/电脑连接在同一局域网；
- `spippy.local` 无法解析时改用设备 IP；
- 长按 BOOT 查看 OLED 上的地址；
- 也可以询问机器人“网页地址”，由 `self.robot.web_console` 返回实时地址；
- 配网 AP 阶段的 80 端口用于 Wi-Fi 配网页面，完成联网后才会启动 Spippy 校准页面。

### OLED 没有显示，但语音和动作正常

检查 OLED 地址、SDA/SCL 接线和供电。OLED 初始化失败时，固件会退化为无屏模式，语音、网络和机器人控制仍可继续工作。

### 舵机抖动或机器人姿态异常

- 确认舵机使用独立、足量的电源；
- 确认舵机电源与主控共地；
- 检查舵机是否接在正确的腿位和关节通道；
- 先运行舵机预检，再进行 90° 零位校准；
- 不要在腿部受力或卡住时执行校准和表演动作。
